Financial Tracker adalah aplikasi mobile yang dirancang untuk membantu pengguna
mengelola dan memantau keuangan pribadi dengan lebih mudah dan terstruktur.

Aplikasi ini memungkinkan pengguna untuk mencatat pemasukan dan pengeluaran,
mengelola wallet, membuat target keuangan, serta melihat analisis kondisi
keuangan mereka

Tujuan dari aplikasi Financial Tracker adalah membantu pengguna:

- Mencatat pemasukan dan pengeluaran dengan mudah.
- Mengetahui kondisi keuangan secara lebih jelas.
- Mengontrol dan mengurangi pengeluaran yang tidak diperlukan.
- Membuat target dan perencanaan keuangan.
- Meningkatkan kesadaran terhadap kebiasaan konsumsi.

Authentication
- Register
- Login
- Logout
- User Profile

Income & Expense
- Add Income
- Add Expense
- Edit Transaction
- Delete Transaction
- Transaction History
- Transaction Detail
- Transaction Categories
- Search Transaction
- Filter Transaction

Wallet Management
Pengguna dapat mengelola berbagai sumber dana seperti:

- Bank Account
- E-Wallet
- Cash
- Credit Card
- Investment

Fitur:
- Add Wallet
- Edit Wallet
- Delete Wallet
- View Wallet Balance
- Transfer Between Wallets

Dashboard
Dashboard menampilkan informasi keuangan pengguna, seperti:

- Total Balance
- Total Income
- Total Expense
- Total Savings
- Recent Transactions
- Spending Summary

Financial Goals
Pengguna dapat membuat target keuangan.

Contoh:
- Membeli Laptop
- Membeli Handphone
- Liburan
- Dana Pendidikan

Fitur:
- Create Goal
- Set Target Amount
- Set Target Date
- Track Goal Progress
- Add Savings to Goal
